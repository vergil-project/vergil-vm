
# Release 2.1.43 (2026-10-16)

## Documentation

- **point host-setup pages at vrg-host for Lima, gcloud and OpenTofu upkeep (#319)**
Getting started, the off-platform cloud setup and troubleshooting now point at vrg-host status/upgrade (and status --fix for gcloud's NumPy check), linking the vergil-tooling vrg-host reference. The cloud setup also lists OpenTofu 1.8+ as a host prerequisite. Ref #318.


## Features

- **add the dependency-update hook and read the vergil series in vrg-vm-init (#320)**
Add scripts/dev/update-deps.sh, wired through [dependency-update].hook, for vrg-update-deps to run in the dev container (epic vergil-project/.github#381, issue #317). It runs tofu init -upgrade per module within the existing ~> ranges, bumps NERDCTL_VERSION to the newest release within its major and regenerates cloud-init.yaml, and reports (never bumps) a newer nerdctl major, a Lima major above minimumLimaVersion, and a Node LTS major above the NodeSource major. Every lookup, parse or tool failure exits non-zero. scripts/vrg-vm-init.sh now installs vergil-tooling at the [dependencies].vergil series from vergil.toml instead of a hard-coded v2.1, failing before any VM side effect when it is missing. New hermetic checks (stubbed curl, tofu and limactl) run from run-host-tests.sh and validate-custom.
