
# Release 2.1.0 (2026-05-22)

## Bug fixes

- **add run-codeql false, container-suffix/tag for audit and test jobs, and Table of Contents to README**
- **remove container-tag from audit and test jobs (not an accepted input)**
- **add missing release job to cd.yml**
- **remove audit and test jobs not required for shell repos**
- **add PATH to readiness probe for user-installed tools**
- **remove Go template syntax, make projects mount required**
Lima 2.1.1 cannot parse Go template control flow (if/end) at the
YAML structural level. Remove the param block and conditional mount.
The projects mount is now unconditional with a placeholder path that
must be overridden via --set at create time.

- **move Claude Code install to system provisioning block**
npm install -g writes to /usr/lib/node_modules/ which requires root. Running in the user provisioning block caused EACCES, failing the readiness probe. Ref #27

## Features

- **Lima VM template for vergil-agent**
Ubuntu 24.04 with rootless containerd, gh, uv, jq, yq, zsh, and developer convenience tools

- **build script for VM creation and testing**
Creates temporary Lima VM, runs test suite, cleans up. Located in scripts/ per project convention.

- **parameterized /projects mount point**
Replace hardcoded ~/dev mount with user-configurable hostProjectsDir param. Host path mounts at /projects inside the VM, making workspace paths deterministic and user-agnostic. Ref #19.

- **install Node.js and Claude Code in VM template**
Add Node.js 22 via NodeSource and Claude Code via npm to provisioning scripts. Add claude readiness probe and tool test. Ref #21

- **credential provisioning via vrg-vm-init**
vrg-vm-init reads identities.toml (or env var overrides), injects
App ID and private key into the VM via limactl shell, configures
git HTTPS rewriting, and installs vergil-tooling. Token acquisition
is fully dynamic at runtime via vrg-git / vrg-gh wrappers.
