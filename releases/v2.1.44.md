
# Release 2.1.44 (2026-10-16)

## Chores

- **land the 2.1.44 dependency update with a hermetic hook test (#330)**
* chore(deps): repo hook

* test(deps): make the update-deps hook check hermetic to the live nerdctl pin (#329)

check-update-deps-hook.sh asserted that the live repo pinned NERDCTL_VERSION=2.3.3 and compared its no-op scenario against the live cloud-init files, so it failed every time the hook did its job (the 2.1.44 update moved nerdctl to 2.4.1). The scenarios now run against a scratch fixture baseline: every vm skeleton is normalized to 2.3.3 with the hook's own set_nerdctl_version, cloud-init.yaml is regenerated with build-cloud-init.sh, and the baseline is asserted to be fresh and normalized. new_repo copies that baseline, and the no-op scenario compares against it. The live-value assertion is gone. No hook-behaviour assertion was weakened.
