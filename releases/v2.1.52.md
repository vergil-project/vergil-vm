
# Release 2.1.52 (2026-11-14)

## Bug fixes

- **ignore provisioner comments in test_base.sh rc checks and keep the host-check lists in step (#410)**
* fix(tests): ignore provisioner comments in test_base.sh rc checks and name failing checks

test_base.sh's ~/.zshrc.local absence check matched the provisioner's own explanatory comment, so it exited 1, silently, on every correctly provisioned VM. Route every assertion through a check() helper that names the failing check, ignore comment text in the absence checks (zshrc.local, UV_PROJECT_ENVIRONMENT), anchor the setopt checks to uncommented lines, and move the rc checks into check_shell_rc so the new host-side tests/check-test-base.sh can run them against the ~/.zshrc and ~/.zshenv heredocs in 30-toolchain.sh. Wired into validate-custom and run-host-tests.sh. Ref #407.

* fix(tests): keep run-host-tests.sh and validate-custom's host-check lists in step

run-host-tests.sh, the list scripts/build.sh runs, had drifted from validate-custom's: it omitted check-azure-volume-id-parse, so build.sh never ran that check while vrg-validate did. Add it, hold both lists as one-name-per-line host_checks arrays between BEGIN/END markers, and add tests/check-host-check-lists.sh, run from both lists, which fails when they differ, naming each check missing from either side (check-opentofu-validate is the one intended difference: validate-custom's tofu step covers it). A malformed list fails rather than being read as a shorter one. Ref #407.


## CI

- **move the nightly ops cron to the 01:xx UTC hour (#415)**
GitHub schedule events are firing 7 to 9 hours late, landing the 06:36 UTC run in the US Eastern working morning. Move it five hours earlier, keeping the per-repo minute stagger, so the lag still lands it overnight.
