
# Release 2.1.47 (2026-10-21)

## Bug fixes

- **seed racc before vagrant-libvirt so the plugin installs on Ruby 3.3 guests (#347)**
Ubuntu 26.04 ships Ruby 3.3, where racc is a bundled gem rather than a
default one. vagrant 2.4.x resolves nokogiri's racc requirement to the
system copy during plugin install, so racc never lands in ~/.vagrant.d/gems,
and vagrant's offline re-check (which sees only default gems plus the plugin
dir) then fails: 'nokogiri (~> 1.6)' requires 'racc (~> 1.4)'.

Install racc as a plugin at a pinned version newer than any distro copy
(VAGRANT_RACC_SEED=1.8.1) before vagrant-libvirt, forcing it into the
plugin dir. A guard fails loudly if the distro racc ever catches up to
the pin.

Also make plugin-install failures honest: a dependency-resolution error is
deterministic, so it fails at once with vagrant's own resolver message
instead of being retried three times and blamed on gems.hashicorp.com;
transient failures still retry and now report the last error.

The helpers are unit-checked by tests/check-vagrant-plugins.sh (stubbed
sudo/vagrant/ruby), wired into validate-custom and run-host-tests.
