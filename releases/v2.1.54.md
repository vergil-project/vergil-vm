# Release 2.1.54 (2026-11-19)

## CI

- **pass the automation App secrets to the release (#431)**
  cd-release.yml pushes the release tag with the automation App's installation token (epic vergil-project/.github#1350, Task 2a), so the release job now passes APP_CLIENT_ID and APP_PRIVATE_KEY, in the explicit style ops.yml and epic-rollup.yml already use. Ref vergil-project/vergil-vm#428

## Documentation

- **name Python 3.15 in the injection step and rewrap the series test header (#426)**

## Features

- **use the vergil-tooling uv install rules (#432)**
  vrg-vm-init.sh no longer installs vergil-tooling or reads the [dependencies].vergil series: vrg-vm create installs it in its tooling stage, so the script's install was a duplicate (epic vergil-project/.github#1350, Task 11). check-vm-init-series.sh becomes check-vm-init-no-tooling.sh, which asserts the script installs none and still injects the credentials with no vergil.toml present. test_vergil.sh now checks the VM's existing install only: no vergil apt package, and on a VM vrg-vm create made, vrg-whoami resolves to ~/.local/bin with no PATH set and runs. Docs updated to match.
- **double the default cloud VM boot disk to 60 GiB (#434)**
  The rootless containerd store lives on the cloud VM's boot disk, so agent container caches fill the 30 GiB default. Raise boot_disk_gib to 60 in the GCP and Azure vm modules, and the ADR line that states it. Ref #433.
