## Features

- **open every port_forwards host port in the browse firewall (#341)**
The -browse firewall rule admitted only tcp:3000, so any other forwarded port was reachable on Lima but blocked on a cloud VM. Derive the rule's ports from the PORT_FORWARDS line of provision_env (the same declaration that creates the relays). Omit the rule when there are no forwards, since an empty ports list would admit every port. Fail the plan on a missing line, a bad port, or port 22. A moved block carries existing state. Add a mocked-provider tofu test suite and run it from validate-custom.
