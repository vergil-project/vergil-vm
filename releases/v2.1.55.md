# Release 2.1.55 (2026-11-23)

## CI

- **stop granting actions: read to the security job (#443)**
  ci-security.yml@v2.1 no longer requests actions: read now that private-repo support is gone (vergil-project/.github#1476), so the grant and its comment go.
- **pass the App secrets to the shared docs workflows (#446)**

## Documentation

- **state the boot and Lima disk defaults and the non-login PATH guarantee (#439)**
  The boot disk is sized by [vm].boot_disk when declared, else the 60 GiB module default. Resource tuning now gives the shared VM's 50 GiB template disk and the dedicated VM's 100 GiB base-footprint disk (vergil-tooling #4791). The provisioning pipeline names the /etc/environment PATH entry that lets non-login remote commands find the uv-installed vrg-* commands. Ref #438
- **state a single 100 GiB default Lima disk for shared and dedicated VMs (#441)**
  vergil-tooling#4810 gives the shared base VM the base footprint's disk (100GiB), like a dedicated VM. Describe one default for both, the per-identity and named-instance overrides, and that an existing shared VM reaches the new size only on rebuild. Ref vergil-project/vergil-vm#440.

## Features

- **double the agent template's default disk to 100 GiB (#445)**
  Set disk to 100GiB in templates/agent.yaml.skel and the generated agent.yaml, matching vrg-vm's base footprint, and show a 200GiB per-identity override. No vrg-vm command grows an existing VM's disk, so document the one-time in-place grow with limactl edit --disk and correct the claim that a restart applies changed CPU or memory. Ref #427.
